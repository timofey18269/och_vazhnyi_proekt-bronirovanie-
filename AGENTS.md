# Инструкции проекта

- Источник требований — `Спецификация_требований_Сервис_бронирования_столов_v2.docx`. Ссылайся на номера FR при реализации и проверке.
- Стек — React SPA на JavaScript, .NET REST API, PostgreSQL с миграциями. API и базу запускаем в Docker. Секреты передаём через переменные окружения.
- Создавай, переноси и отменяй брони в транзакциях. PostgreSQL должен запрещать пересечение активных броней одного стола с учётом буфера (FR.25–26). Проверяй конкурентное бронирование на PostgreSQL.
- Проверяй роли и принадлежность брони на сервере (FR.3, FR.62). Храни время в UTC, показывай его в часовом поясе ресторана.
- Добавляй в документацию команды запуска и тестирования после их проверки. Временные файлы Word (`~$*.docx`) не добавляй в Git.
